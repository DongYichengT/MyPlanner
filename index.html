数据安全与本地备份

您的所有打卡数据均安全加密保存在本地浏览器中，绝无隐私泄露风险。建议定期导出 JSON 备份文件，方便更换设备时一键导入恢复。

体验与快捷选项

想要快速预览打卡热力图和图表效果？您可以一键载入两周的示例打卡记录；也可以重置并清空所有记录从零开始。

如何部署到您的 GitHub Pages

本项目为纯静态现代网页，无任何依赖与构建步骤，30秒即可免费上线：

  1. 在 GitHub 上新建一个仓库（如 daily-checkin）。
  2. 将本文件夹内所有文件通过 Git 推送（Push）到该仓库的 main 分支。
  3. 在 GitHub 仓库主页，点击 Settings ➔ Pages。
  4. 在 Branch 下拉框选择 main，目录选择 / (root)，点击 Save。
  5. 等待约 30 秒，刷新页面即可获得您的专属在线打卡网址！
